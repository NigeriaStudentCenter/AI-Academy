Before you start

Frequently asked questions

Do I need existing SQL or Python experience?

Some familiarity helps, but the SQL and Python labs are built to teach hands-on with AI assistance — you don't need to already be fluent in either.

Is this the same as the official PL-300 Microsoft certification?

No. This BSOE Academy course aligns closely with PL-300's scope and even references official Microsoft exam-prep episodes, but it is not the official certification itself. Think of it as strong preparation that complements, rather than replaces, sitting the real PL-300 exam.

What is the capstone project?

An end-to-end project: you scope a business question, clean and model the data, analyse it with AI assistance, validate the results, visualise them, and present recommendations with commentary.

How does this course handle data governance?

Module 4 is dedicated to Purview lineage, sensitivity labels, DLP and human-in-the-loop safeguards — treated as a core analyst responsibility, not an IT-only concern.

How long does this course take?

Seven modules covering 24 lessons and labs, roughly 14 hours 47 minutes of content in total. Most learners work through one module per sitting.
