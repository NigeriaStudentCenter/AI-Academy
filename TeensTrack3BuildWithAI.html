TRACK 3 OF 4

Track 3 — Build with AI (no-code)

Turn a real, local problem into a working tool — no coding required. This track holds the capstone: a tool a real stranger can use, tested on three real people before it ships.

Badge: BuilderProject: Capstone — a working tool

What's inside

Each module has a clear goal, a copyable prompt to practise with, a hands-on activity and a quick check — done in the Academy's own Microsoft 365 account, so a learner's own writing stays inside the school's tenant.

MODULE 1

From idea to spec

Goal: Choose one narrow, visible problem, write a one-paragraph spec, and let AI help turn it into a build plan — steps, content needed, and the screens or messages required.

MODULE 2

Build it

Goal: Pick the simplest no-code route for the idea and the device it'll run on, then load real content and write the instructions that make it behave.

MODULE 3

Test and ship

Goal: Watch three real users try the tool without help, then package it so a stranger can use it unaided.
