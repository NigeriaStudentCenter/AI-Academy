Design the Experience Before You Build

Module 3 identified what problem is worth solving. Module 4 decides what the customer experience should look like.

An AI agent is not simply a chatbot with a language model behind it. It is part of a service experience. Design must make clear what the agent is responsible for, what information it can use, what actions it can take, when it should ask questions, when it should stop and when a human takes over.

1 · Short Teaching Video / HeyGen Script

Designing an Agent, Not Just a Chatbot

Recommended length: 7–9 minutes.

Welcome to Module 4 of the BSOE AI Academy.

In the previous module, you discovered a customer opportunity. Now we are going to design the experience that will address it.

The first principle is simple: do not begin with technology. Begin with the customer, the outcome and the agent's responsibility.

Imagine a customer asks, “Where is my order?” A weak design might simply tell a language model to answer questions. A stronger design asks: What information is required? How do we know whose order this is? Which system contains the current status? What is the agent allowed to reveal? What happens if the information is unavailable? And when should a person become involved?

This is the difference between a conversation and an agent experience.

We can describe the experience as a journey. The customer expresses an intent. The agent identifies the request. It gathers the necessary context. It retrieves approved information. It may use a tool to take an authorised action. It explains the result and confirms what happens next.

But good design also includes stopping points. If the customer asks for something outside the agent's role, the agent should say so. If the request is high-risk, sensitive or ambiguous, the design should route it appropriately. If a human is required, escalation should be part of the experience rather than an emergency workaround.

Finally, define success before you build. Are customers getting answers faster? Are they completing tasks successfully? Is information accurate? Are humans receiving better-quality escalations? Is satisfaction improving?

Your output from this module is an Agent Experience Blueprint. It becomes the design foundation for the build stage.

Design the experience first. Then build the technology that makes the experience possible.

3 · Interactive Example

Design the Same Agent at Two Levels

Level 1 — vague

Admissions AI Assistant

Helps applicants with admissions.

Problem: The role is too broad. Boundaries, data, actions and escalation points are unclear.

Level 2 — designed

Admissions Application Support Agent

Helps authenticated applicants understand published requirements and retrieve current application status using approved university information.

Boundary: It does not make admissions decisions or give definitive eligibility judgements.

4 · Case Study

Retail Returns Agent

A national retailer receives thousands of contacts about returns. Customers ask whether an item is eligible, how to return it, whether a return has arrived and when a refund will be issued.

Customer problem

Customers struggle to understand the return process and repeatedly contact staff for status updates.

Agent opportunity

Guide customers through published return rules and retrieve authorised return/refund status.

Human boundary

Disputed refunds, exceptions, suspected fraud and policy overrides are routed to trained staff.

StageAgent behaviourControl
IntentIdentify return question or status request.Clarify when needed.
ContextObtain order/return reference and authenticate where required.Do not expose another customer's information.
KnowledgeUse current approved return policy.Prefer authoritative sources.
ToolRetrieve return/refund status.Read-only access where possible.
ActionPerform only authorised actions.Confirmation before consequential action.
EscalationTransfer complex/disputed cases.Preserve context for the human.
Case lesson: The agent is not designed to “handle returns.” It is designed to perform a defined set of customer-support jobs safely.
