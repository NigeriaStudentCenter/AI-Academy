Example AI-Readiness Report

What a finished audit looks like — a worked example you can learn from and copy.

Worked exampleFictional API

This is a sample report for a made-up "ShopEasy Orders API", scored with the 10-pillar check.

It shows what a professional AI-readiness audit looks like — the kind of deliverable you could produce for a business (or your own project) after completing the API lessons.

78
Grade B
ShopEasy Orders API · 7 of 10 pillars met

Findings by area

API design

Strong
  • Clear map: endpoints list path, inputs and response shape.
  • Typed fields throughout.
  • Consistent naming (camelCase everywhere).

Agent understanding

Needs work
  • Predictable shape: mostly, but the "search" endpoint returns a different structure — fix this.
  • Worked examples: present for the main endpoints, missing for errors.

Error handling

Weak
  • Rich errors: several endpoints return only {"error":"failed"} — no code or fix hint.
  • Recommended fix: add a code, field and message to every error.

Discovery & docs

Strong
  • Open, public documentation that's easy to read.
  • Clear authentication instructions.
  • Published where tools can find it.

Reliability

Needs work
  • Fast on most calls, but the "reports" endpoint is slow (5–8s) and would time agents out.

Summary

Top 3 strengths: clear map, consistent naming, and great public docs.
Top 3 gaps: weak error messages, one inconsistent response shape, and a slow endpoint.
Biggest quick win: upgrade error responses — it lifts the grade most for the least effort.

Generate reports like this — with AI

Once you can read an API's docs, AI can help you produce a polished audit. Try:

Act as an API reviewer. I'll paste an API's documentation. Score it out of 100 against these 10 AI-readiness pillars [paste the 10], give a letter grade, group findings by area as Strong/Needs work/Weak, and end with the top 3 strengths, top 3 gaps, and the single biggest quick win.

This is a real, sellable skill — an "AI-readiness audit" you can offer businesses, produced with tools you already know.
