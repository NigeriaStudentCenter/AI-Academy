Why this matters

AI-assisted delivery is now the default — securing it isn't optional.

Copilot-assisted coding is already standard practice. The skill gap that matters now is building, deploying and operating that code responsibly.

Coding is already AI-assisted

GitHub Copilot and Microsoft 365 Copilot are already inside the IDE and the workplace — this course is about using them with rigour, not discovering them for the first time.

Security can't be bolted on later

DevSecOps, DLP, ALM and supply-chain risk are treated as core delivery skills here, built into CI/CD from the start rather than retrofitted before release.

Observability makes AI systems trustworthy

Telemetry, evaluation and cost/latency monitoring turn a working prototype into a system you can actually run in production and debug with confidence.

Human review stays in the loop

Even with agentic, end-to-end development, this course keeps a person reviewing what ships — speed doesn't replace judgement.

Before you start

Frequently asked questions

Do I need existing coding experience?

Yes. This course assumes you're already writing code or working in IT/DevOps — most content is Intermediate to Advanced, though a few Beginner-level lessons introduce specific Azure and security concepts.

What is the capstone project?

A secure RAG web app built on Azure: you implement identity and content safety, deploy it via GitHub Actions, add telemetry and cost monitoring, and present a responsible-AI review and runbook.

Does agentic development mean AI decides what ships?

No. Every module keeps human review central — AI accelerates coding, testing and deployment, but a person still reviews and approves what goes to production.

Why is one lesson marked "Archived"?

A referenced GitHub Copilot agentic-development demo has since been archived by its source platform. It's listed for context, not as something you need to complete.

How long does this course take?

Five modules covering 22 active lessons and labs, roughly 16 hours 50 minutes of content in total. Most learners work through it one module at a time.
